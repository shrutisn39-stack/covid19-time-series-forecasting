# covid19-time-series-forecasting
Time-series forecasting of COVID-19 cases using Machine Learning models including Linear Regression and Facebook Prophet, with performance comparison.
# 📈 COVID-19 Forecasting using Machine Learning

## 📌 Project Objective
To forecast COVID-19 confirmed cases using time-series analysis and compare the performance of Linear Regression and Prophet models.

## 🛠️ Tools & Technologies
- Python  
- Pandas, NumPy  
- Matplotlib  
- Scikit-learn  
- Facebook Prophet  
- Google Colab  

## 📊 Models Used
- Linear Regression  
- Prophet (Time-Series Forecasting)

## 📈 Key Insights
- Prophet model captured trends and seasonality better than linear regression  
- Linear model performed well for short-term predictions  
- Forecasting helps in understanding future case growth
